# Maple Messenger

כלי קטן ל-MapleStory: מקליד בצ'אט של השוק שתי הודעות לסירוגין, כל כמה שניות, כאילו הקלדת אותן במקלדת.

> **בעבודה.** כרגע יש כאן רק את הבסיס: בניית רצף המקשים, החלפה בין שתי ההודעות ושמירת ההגדרות, עם בדיקות. החלון והחלק שמקליד בפועל עוד לא נכתבו.

## איך זה אמור לעבוד
- שתי הודעות נשלחות לסירוגין, וכל אחת מוקלדת כך: Enter לפתיחת הצ'אט, הטקסט, ו-Enter לשליחה.
- ההקלדה נשלחת לפי קודי מקשים, כמו ממקלדת אמיתית, ובהתאם לשפת המקלדת שפעילה במשחק.
- הכלי מקליד רק כשחלון של מייפל בפוקוס. אם עוברים לחלון אחר, ההקלדה נעצרת מיד.
- מקש קיצור (ברירת מחדל F9) מפעיל ועוצר מתוך המשחק.

## בנייה
```
dotnet build
dotnet test
```
דורש .NET 9 ו-Windows.
