# Maple Messenger

כלי קטן ל-MapleStory למי שמוכר בשוק: מקליד בצ'אט שתי הודעות לסירוגין, כל כמה שניות, כאילו הקלדת אותן במקלדת.

## הורדה
לוחצים על הקובץ [`MapleMessenger.exe`](MapleMessenger.exe) ברשימת הקבצים למעלה, ואז על כפתור ההורדה (Download raw file). מפעילים אותו בלחיצה כפולה, ולא צריך להתקין כלום.

בהפעלה הראשונה Windows עלול להציג "Windows protected your PC", כי הקובץ לא חתום. לוחצים **More info** ואז **Run anyway**.

## איך משתמשים
1. כותבים את שתי ההודעות. למשל `S> ...` למה שמוכרים ו-`B> ...` למה שקונים.
2. בוחרים כל כמה שניות לשלוח (3 עד 600).
3. נכנסים למשחק ולוחצים **F9** (או המקש שבחרת). ההודעות יוצאות בתורות: 1, 2, 1, 2...
4. עוד לחיצה על המקש עוצרת.

## על מה שמרנו
- **מקליד רק במייפל.** הכלי מקליד רק כשהחלון שבפוקוס שייך לתוכנה שבשם שלה מופיע "maple", כמו MapleStory.exe ורוב השרתים הפרטיים. אם עוברים לחלון אחר, ההקלדה נעצרת מיד, אפילו באמצע שורה, ואף מקש לא נשאר לחוץ.
- **כמו מקלדת אמיתית.** כל אות נשלחת לפי קוד המקש הפיזי, ו-Shift נשאר לחוץ לאורך רצף של אותיות גדולות, כמו שאדם מקליד.
- **שפת מקלדת.** אם המקלדת במשחק בעברית, הכלי לא מקליד ג'יבריש. הוא עוצר ומבקש לעבור לאנגלית (Alt+Shift). גם Caps Lock מטופל.
- **לא נוגע בקיצורים.** אם Shift, Ctrl או Alt לחוצים, הכלי מחכה שישחררו אותם.
- **הרשאת מנהל.** אם המשחק רץ כמנהל, Windows לא נותן לתוכנה רגילה להקליד בו. הכלי מזהה את זה ומציע כפתור שמפעיל אותו מחדש כמנהל.

## פתיחת הצ'אט עם Enter
כברירת מחדל כל הודעה נשלחת כך: Enter (פותח את הצ'אט), הטקסט, ו-Enter (שולח). אם אצלך הצ'אט נשאר פתוח אחרי שליחה, כבה את האפשרות הזאת, אחרת ה-Enter הראשון יסגור אותו.

## כדאי לדעת
- שימוש בכלים כאלה נוגד את תנאי השימוש של Nexon. האחריות על החשבון שלך.
- אם מערכת ההגנה של המשחק חוסמת הקלדה מתוכנה, הכלי לא עוקף אותה.
- ההגדרות נשמרות לבד ב-`%APPDATA%\MapleMessenger\settings.json`.

## בנייה מהקוד
```
dotnet test
dotnet publish src/MapleMessenger -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```
דורש .NET 9 ו-Windows.
